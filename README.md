# CallSight for Mac

Download the latest version: [CallSight.dmg](https://github.com/omerbhr129/callsight-desktop-releases/releases/latest/download/CallSight.dmg)

Open it and drag CallSight to Applications. The app updates itself after that.

More at [callsight.app](https://callsight.app). This repository holds releases only; the app's code is private.
